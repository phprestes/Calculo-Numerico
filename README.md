## 📋 Requisitos

- **Python 3**
- **Jupyter** (JupyterLab, Notebook, VS Code ou Google Colab)

## 🚀 Como Executar

```bash
jupyter lab
```

Abra o notebook desejado no ambiente Jupyter.

## 📂 Estrutura do Projeto

- `01_bases_numericas.ipynb`: conversão e representação em diferentes bases numéricas.
- `02_ponto_flutuante.ipynb`: aritmética de ponto flutuante, erros de arredondamento e truncamento.
- `03_zeros_reais.ipynb`: métodos para encontrar raízes de funções (Bisseção, Newton-Raphson, Secante).
- `04_sistemas_lineares.ipynb`: sistemas lineares por métodos diretos (Eliminação de Gauss, Fatoração LU).
- `05_sistemas_nao_lineares.ipynb`: sistemas de equações não lineares (Método de Newton).
- `/Projetos`: `pendulo_simples.ipynb` e o enunciado do Projeto 03 (`SME0104_2026_Projeto_03.pdf`).

## ✨ Funcionalidades Implementadas

- **Representação numérica**: conversão entre bases e análise de erros de ponto flutuante.
- **Busca de raízes**: Bisseção, Newton-Raphson e Secante.
- **Sistemas de equações**: Eliminação de Gauss, Fatoração LU e Método de Newton para sistemas não lineares.
- **Explicação passo a passo**: cada notebook desenvolve e explica seus exemplos para facilitar a visualização dos algoritmos.
