## Estrutura do Repositório

O repositório contém uma série de Jupyter Notebooks focados na implementação computacional e explicação teórica de métodos numéricos. Os tópicos abordados estão divididos da seguinte forma:

- `01_bases_numericas.ipynb`: Conversão e representação em diferentes bases numéricas.
- `02_ponto_flutuante.ipynb`: Aritmética de ponto flutuante, erros de arredondamento e truncamento.
- `03_zeros_reais.ipynb`: Métodos para encontrar raízes de funções (Bisseção, Newton-Raphson, Secante, etc.).
- `04_sistemas_lineares.ipynb`: Resolução de sistemas de equações lineares por métodos diretos (Eliminação de Gauss, Fatoração LU).
- `05_nao_lineares.ipynb`: Resolução de sistemas de equações não lineares (Método de Newton).

Todos os exemplos são desenvolvidos e explicados ao longo de cada notebook para facilitar a visualização e aplicação prática dos algoritmos.
